# Lumen Read 2.1.0

## English

- A major local reading-engine update, with optional Adaptive presentation
  (Beta) to improve EPUB readability while preserving meaningful book styling.
- Improvements to navigation, saved reading positions and visual page estimates.
  Page totals depend on typography and window dimensions, not the printed edition.
- Fixed local progress persistence when reading-state fields are reactive objects.
- More explicit permission and data-sharing controls for optional AI and Dropbox.
  Local-model download access is requested only when the user enables downloads.
- Clearer provider-access and connection-test states, usable AI setup in narrow
  sidebars, and translated Dropbox authorization feedback.
- Bundled interface fonts and icons; extension builds omit GTM and Sentry telemetry.
- Firefox build hardening removes Zod's dynamic-code probe without weakening CSP.

Ordinary reading requires no Lumen account or AI key. Adaptive is off by default
in production and does not guarantee repairs for every EPUB. Remote AI and
Dropbox remain optional and use the selected services' privacy terms.

## Português

- Grande atualização do motor local de leitura, com Apresentação adaptativa
  (Beta) opcional para melhorar a legibilidade preservando o estilo do livro.
- Melhorias de navegação, posição salva e estimativas visuais de páginas.
  O total depende da fonte e da janela, não da edição impressa.
- Correção da gravação local do progresso quando os dados de leitura são reativos.
- Controles mais explícitos de permissão e envio de dados para IA e Dropbox.
  O acesso para baixar modelos locais só é pedido quando o usuário habilita os downloads.
- Estados claros de acesso ao provedor e teste de conexão, configuração da IA
  utilizável em barras laterais estreitas e avisos de Dropbox traduzidos.
- Fontes e ícones incluídos no pacote; builds da extensão sem GTM e Sentry.
- Remoção da sondagem de código dinâmico do Zod sem enfraquecer a CSP.

A leitura comum não exige conta do Lumen ou chave de IA. O modo Adaptativo vem
desativado em produção e não garante corrigir todo EPUB. IA remota e Dropbox
são opcionais e seguem as políticas dos serviços escolhidos.

## Install and update

- **Firefox:** install or update through [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/lumen-read/).
  This GitHub release does not imply that Mozilla has approved or published the
  same version. The Firefox ZIP is for AMO submission or temporary developer
  loading; it is not a signed Firefox install package. Minimum Firefox: 142.
- **Chrome, Edge and other Chromium browsers:** extract `Lumen-chrome.zip`, enable
  Developer mode on the extension-management page and choose **Load unpacked**.
  Lumen is not published in the Chrome Web Store.
- **Source:** `Lumen-read-source-2.1.0.zip` contains the reviewed source and build
  instructions for this version, including local UI fonts and their licenses.
  See the root README and [Firefox reviewer notes](https://github.com/Zolangui/Lumen-Read/blob/v2.1.0/docs/firefox-reviewer-notes-2.1.0.md).

## Verification and limits

96 reader-core tests passed on 2026-10-10; 1,391 engine tests passed on
2026-10-08. Offline
provider checks, AI release-safety checks and the local-font/icon smoke tests
passed; the latter exercised Firefox and Edge on Windows.

The preceding production Firefox smoke tests exercised the reader, optional
Adaptive on/off, consent denial/revocation, narrow AI setup and loopback chat.
They do not establish complete compatibility or an independent security audit.
Genuine cloud-provider authentication, full Dropbox synchronization, signed-AMO
installation/upgrade consent, Firefox 142, Android and Linux were not exercised
in that smoke test. These limits must not be advertised as verified features.

The final Firefox package was retested on 2026-10-10 for importing an original
sample, chapter navigation, returning to the library and restoring canonical
position/progress; no unhandled errors were observed in those flows.
Mozilla addons-linter reported zero errors and nine source-attributed warnings.
A source-archive rebuild in a separate directory reproduced all 79 extracted
Firefox package files byte-for-byte on the documented Windows environment.

The final Chromium ZIP was loaded unpacked in an isolated Edge profile. The
library, EPUB import/cover/page navigation and AI setup sidebar rendered without
unhandled errors in the exercised flows. This is not a full Chrome compatibility
matrix or a test of genuine AI authentication.
