# Lumen Read 2.1.1

## English

Lumen's local reading engine includes **Adaptive presentation (LPE, Beta)**:
an optional way to improve EPUB legibility, especially dark text against dark
backgrounds, while preserving meaningful book colours and styling. Enable it
in Theme. It remains off by default and cannot repair every EPUB.

New since 2.1.0:

- **Local backup controls:** export the entire library or selected books, with
  optional global preferences and reading history/calendar.
- Restore EPUBs, covers, annotations/notes, saved chats, reading positions and
  per-book typography. Choose whether to restore global preferences/history.
- SHA-256 verification for newly exported EPUB files, validation before writes,
  same-name file support, and explicit failures for missing/corrupt files or
  conflicting book IDs. Reimporting the same history does not inflate totals.
- Translated backup controls and errors in all seven supported interface languages.
- Fixed a closed sidebar intercepting clicks on narrow screens.
- Fixed merging an incoming book when no local record exists.

The backup ZIP is **not encrypted**. Keep it private. API keys, service
authorizations, downloaded models and rebuildable indexes/page caches are not
exported. Dropbox synchronization is preserved as a separate optional feature;
creating a local backup does not upload anything.

## Português

O motor local do Lumen inclui a **Apresentação adaptativa (LPE, Beta)**:
uma opção para melhorar a legibilidade de EPUBs, especialmente texto escuro
sobre fundo escuro, preservando cores e estilos relevantes do livro. Ative em
Tema. Continua desativada por padrão e não garante corrigir todo EPUB.

Novidades desde a 2.1.0:

- **Backup local:** exporte a biblioteca inteira ou livros selecionados, incluindo
  opcionalmente preferências globais e histórico/calendário de leitura.
- Restaure EPUBs, capas, anotações/notas, chats salvos, posições de leitura e
  tipografia por livro. Escolha se deseja restaurar preferências/histórico.
- Verificação SHA-256 dos EPUBs em novos backups, validação antes da gravação,
  suporte a arquivos com nomes iguais e erros claros para arquivos ausentes,
  corrompidos ou IDs conflitantes. Reimportar o mesmo histórico não infla o total.
- Controles e erros traduzidos nos sete idiomas disponíveis.
- Correção da sidebar fechada que bloqueava cliques em telas estreitas.
- Correção ao mesclar um livro recebido sem registro local existente.

O ZIP **não é criptografado**: mantenha-o privado. Chaves de API, autorizações,
modelos baixados e caches reconstruíveis não são exportados. A sincronização
Dropbox continua opcional e separada; o backup local não envia dados à nuvem.

## Installation and submission

- **Firefox:** `Lumen-firefox.zip` is an unsigned package for AMO submission or
  temporary developer loading. This GitHub release does not mean Mozilla has
  published or approved it. For normal installation, use
  [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/lumen-read/).
  Minimum Firefox version: 142.
- **Chrome / Edge / Chromium:** extract `Lumen-chrome.zip`, enable Developer mode
  in the browser's extension manager and select **Load unpacked**. Lumen is not
  published in the Chrome Web Store.
- **Source:** `Lumen-read-source-2.1.1.zip` contains original source, the local
  engine, dependencies lockfile and build instructions. Submit this alongside
  the Firefox package when Mozilla asks for source code. See
  [reviewer notes](https://github.com/Zolangui/Lumen-Read/blob/v2.1.1/docs/firefox-reviewer-notes-2.1.1.md)
  and the [backup guide](https://github.com/Zolangui/Lumen-Read/blob/v2.1.1/docs/readers/local-backup.md).

## Verification and limits

On 2026-10-10, 129 reader-core tests passed, including 32 backup tests.
Production builds run type checking, lint and package-output checks. Offline
provider and AI release-safety checks passed. Backup logic was exercised with
real browser File/IndexedDB in isolated Firefox and Edge profiles.

The packaged Firefox UI test exercises importing two original sample EPUBs,
whole-library/selected export, original file bytes, private-state exclusion,
corruption rejection, restoration and repeated-import history deduplication.
Saved notes/chats/position/typography are seeded test facts, not claims that the
test manually created each via the annotation/chat UI.
The restored book rendered again; English/Portuguese controls and native clicks
in a narrow window also passed. Mozilla addons-linter 10.13.0 reported zero
errors and nine source-attributed warnings.
A separate-folder build from the source archive reproduced all 79 extracted
Firefox package files byte-for-byte on Windows/Node 18.20.8/pnpm 10.6.4;
ZIP container timestamps were not compared. Local UI fonts/icon ligatures
also passed their Firefox and Edge smoke checks.
The final Chromium package was loaded unpacked in Edge 155 in an isolated
profile: backup controls rendered, the Firefox-generated ZIP restored two books,
and the restored EPUB rendered without unhandled errors in the exercised flow.

Backups are not a crash-atomic transaction across IndexedDB and localStorage,
nor an exact reconciliation protocol for independently compacted multi-device
reading histories. Close other Lumen windows before restoring and keep the ZIP.
Older backups with overwritten same-name files cannot recover missing data.

Genuine AI authentication, full Dropbox synchronization, signed-AMO install/
upgrade consent, Firefox 142, Android/Linux and a complete EPUB compatibility
matrix are not represented as completed tests. These checks are not an
independent security audit.
